# Видеофайлы БПЛА

Сюда кладите видео (MP4/GIF), которые воспроизводятся в видеопотоках БПЛА.
Файлы из этой папки раздаются Vite по адресу `/videos/<имя-файла>`.

## Назначение (фиксированные имена)

| Борт (камера)                       | Файл          | URL                     | Модель детекции        |
|-------------------------------------|---------------|-------------------------|------------------------|
| БПЛА «Альфа»  (cam-drone-01)        | `pojar-1.mp4` | `/videos/pojar-1.mp4`   | YOLOv8n-Fire (D-Fire)  |
| БПЛА «Бета»   (cam-drone-02)        | `pojar-2.mp4` | `/videos/pojar-2.mp4`   | YOLOv8n-Fire (D-Fire)  |
| БПЛА «Гамма»  (cam-drone-03)        | `pojar-3.mp4` | `/videos/pojar-3.mp4`   | YOLOv8n-Fire (D-Fire)  |

## Как добавить видео

1. Положите файл в эту папку с точным именем: `pojar-1.mp4`, `pojar-2.mp4`, `pojar-3.mp4`.
2. Когда файл появится на диске, бэкенд сам запустит анализ этого видео
   (первый запрос к `/api/vision/analysis/{camera_id}`), результат закэшируется
   в `backend/app/ml/analysis/`.
3. Если имя отличается — поправьте соответствие в **двух** местах:
   - `backend/app/services/fire_detector.py` → `DRONE_VIDEOS`;
   - `frontend/src/droneMedia.ts` → `CAMERA_MEDIA`.

Поддерживаются `.mp4`, `.webm`, `.ogg`, `.gif`. Видео проигрывается автоматически (без звука).
